| Form | Rule |
| --- | --- |
| Affirmative (+) | I / you / we / they + base form of the verb<br>he / she / it + verb + -s / -es / -ies |
| Negative (–) | I / you / we / they + don't + base form<br>he / she / it + doesn't + base form |
| Question (?) | Do + I / you / we / they + base form ...?<br>Does + he / she / it + base form ...? |
| Frequency adverbs | usually, sometimes, always, never, often, seldom, every day, on Mondays... |
