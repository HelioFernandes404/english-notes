Objetivo da Reunião

Revisar o Simple Past para uso em contextos profissionais de DevOps.

Principais Conclusões

  - Regra Fundamental: Use a forma base do verbo após did ou didn't. Isso evita a conjugação dupla e é o erro mais comum.
  - Verbos Irregulares: Aprenda as formas no passado de verbos-chave do DevOps, como build → built e catch → caught, para descrever com precisão o trabalho passado.
  - Verbo "to be": Use was para sujeitos no singular (I, he, she, it) e were para sujeitos no plural (you, we, they).
  - Exercício Prático: Corrigimos 10 erros de verbo em uma mensagem de Slack simulada, aplicando diretamente as regras aprendidas.

Tópicos

Simple Past: Estrutura e Uso

  - Uso: Para ações concluídas em um momento específico no passado ou para descrever uma sequência de eventos.
  - Estruturas:
      - Afirmativa: Sujeito + Verbo no Passado (I checked the logs.)
      - Negativa: Sujeito + didn't + Verbo Base (I didn't water the plants.)
      - Interrogativa: Did + Sujeito + Verbo Base (Did you write the requirements?)
  - Verbo "to be":
      - was → I, he, she, it
      - were → you, we, they
      - Ex.: The stand-up was at 11:45.

Verbos Regulares: Regras de Ortografia

  - Maioria dos Verbos: Adicione -ed (work → worked).
  - Verbos Terminados em e: Adicione -d (love → loved).
  - Verbos Terminados em Consoante + y: Mude y → ied (try → tried).
  - Verbos Terminados em Vogal + y: Adicione -ed (play → played).
  - Verbos Curtos (CVC): Dobre a consoante final e adicione -ed (stop → stopped).

Verbos Irregulares: Foco em DevOps

  - Verbos de Rotina: wake up → woke up, make → made, run → ran.
  - Verbos de DevOps:
      - break → broke
      - send → sent
      - build → built
      - spend → spent
      - lose → lost
      - catch → caught
      - begin → began
      - think → thought
      - understand → understood
      - tell → told
  - Padrão de Ortografia: Para verbos como caught e thought, o gh é mudo, resultando em um som de t no final.

Exercício Prático: Correção de Erros de Verbo

  - Corrigimos 10 erros de verbo em uma mensagem de Slack simulada de um desenvolvedor júnior.
  - Erros Corrigidos:
      - get up → got up
      - don't see → didn't see
      - break it → broke (o verbo break deve ser conjugado, não o substantivo build)
      - tried → tried (corrigido um erro de digitação)
      - didn't found → didn't find (forma base após didn't)
      - logs was → logs were (sujeito no plural requer were)
      - go → went
      - ask → asked
      - explain → explained
      - app work it → app worked
      - did you solve → did you see (verbo incorreto)
      - didn't had → didn't have (forma base após didn't)
      - to check it → to check (forma base após to)
  - Correções de Pronúncia:
      - late (tarde) vs. later (mais tarde)
      - message (mensagem) vs. messenger (mensageiro)
